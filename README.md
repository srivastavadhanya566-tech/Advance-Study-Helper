# Advance Study Helper

A Java and Python-based productivity engine designed to automate unstructured student text analysis, parse raw study materials, and track academic progress.

## Key Features
* **CLI Productivity Engine:** Command-line tool built in Java to automate unstructured notes parsing, dynamic flashcard extraction, and study directory generation.
* **Algorithmic Text Processing:** Implemented custom string tokenization logic to strip low-value stop-words and auto-categorize study resources by keyword frequency.
* **Local Data Storage:** Built data persistence pipelines using Java File I/O APIs (`File`, `FileWriter`) to map processed text into structured local directories.
* **Cross-Language Pipeline:** Developed a Python script to extract, transform, and load Java-generated outputs into tabular datasets (`.csv`) for progress tracking.

## Tech Stack
* **Languages:** Java, Python
* **Core Concepts:** File I/O, Data Serialization, Text Tokenization
