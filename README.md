# Study Helper - HTML/CSS frontend

java-app/StudyHelper.java and analytics.py are your original files, unchanged.

## Run
1. cd java-app && javac StudyHelper.java
2. cd .. && npm install        (first time only)
3. npm start
4. Open http://localhost:3000

Needs Node.js, a JDK, and (for the analytics button) Python with pandas + matplotlib.
First thing to do in the page: create a folder (e.g. General) before saving notes.

## Files you can restyle
public/index.html - structure | public/style.css - look | public/script.js - tiny glue code
